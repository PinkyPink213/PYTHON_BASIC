Function คือชุดคำสั่งที่ตั้งชื่อไว้เพื่อเรียกใช้ซ้ำ

```python
def greet(name):
    return "Hello, " + name
```

## `return` กับ `print`

- `print()` แสดงผลให้คนดู
- `return` ส่งค่ากลับเพื่อเก็บหรือคำนวณต่อ
- Function ที่ไม่มี `return` จะส่งค่า `None` กลับมา
