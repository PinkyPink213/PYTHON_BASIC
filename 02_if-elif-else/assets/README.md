# Assets — Chapter 02

ภาพในโฟลเดอร์นี้สร้างด้วย OpenAI image generation สำหรับบทเรียนนี้

## Choice Sets

| Theme | ตัวเลือก |
|---|---|
| `animals/` | `cat.png`, `rabbit.png`, `dog.png` |
| `food/` | `pizza.png`, `cupcake.png`, `sushi.png` |
| `fantasy/` | `dragon.png`, `unicorn.png`, `slime.png` |

ครูใช้ animals สาธิต Mystery Animal ก่อน จากนั้นเด็กเลือก food หรือ fantasy
เพื่อสร้างเกมของตัวเองโดยเปลี่ยน secret item, hints และ image paths ให้สัมพันธ์กัน

ภาพชุดพร้อมใช้ช่วยให้เริ่มเขียนโค้ดได้ทันที ส่วนการเปลี่ยนภาพควรทำหลังเกมทำงานแล้ว
